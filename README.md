# micronix

micronix is a high-performance RTOS running on embed arm platform build on C++20.

## Features
+ Bootloader x
+ Slab Allocator √
+ MultiProcess x
+ ROFS(Read-Only FileSystem) Subsystem √
+ RWFS(Read-Write FileSystem) Subsystem x
+ NVDB(Non-Volatile DataBase) Subsystem x
+ Luciferin(2D Graphics) Subsystem √
+ SPL(Standard Peripheral Library) o

## Support Platforms
+ STM32G030C8
+ RP2040
